# המרחב של שירה | אזרחות וחינוך פיננסי – תיכון מקיף ז׳

פלטפורמת למידה ותרגול אינטראקטיבית, חווייתית ומקצועית לתלמידי ותלמידות המורה **שירה** בתיכון **מקיף ז׳**.

---

## 🌟 מה באתר?

1. **דף פתיחה מרכזי ומזמין משירה:**
   - ברכה אישית חמה לתלמידי מקיף ז׳.
   - "הטיפ היומי של שירה" (טיפים מתחלפים לאזרחות, פיננסים ומוטיבציה).
   - מעקב הישגים אישי: רצף למידה (Streak), נקודות XP, ותגי הצטיינות.

2. **מרחב אזרחות:**
   - **חטיבת ביניים (כיתות ז׳-ט׳):** מושגי יסוד בדמוקרטיה, שלטון העם, הכרעת הרוב, זכויות האדם והאזרח, שלטון החוק והפרדת רשויות.
   - **חטיבה עליונה (הכנה לבגרות שאלון 034281):** שאלות ידע, שאלות השוואה, עקרונות המשטר, מאפייני המדינה היהודית והדמוקרטית, וגישות כלכליות-חברתיות.
   - משוב מיידי וטיפים פדגוגיים להצלחה במבחן.

3. **מאמן צה״ס לבגרות (ציין ➔ הצג ➔ הסבר):**
   - כלי ייחודי לבדיקה אוטומטית מלאה של שאלות אירוע רשמיות מבחינות הבגרות (שאלון 034281).
   - פירוק מודרך לשלושת שלבי הבגרות:
     * **שלב 1 (ציין):** זיהוי המושג/זכות/עיקרון מתוך הקטע.
     * **שלב 2 (הצג):** בחירת ההגדרה התיאורטית המדויקת ממונחון משרד החינוך.
     * **שלב 3 (הסבר):** ציטוט מדויק וקישור לוגי למקרה.
   - מצב כתיבה חופשית עם מחוון בדיקה רשמי של מפמ״ר אזרחות (Checklist ודגם תשובה מלא).

4. **חינוך פיננסי וזכויות נוער עובד:**
   - טבלת שכר מינימום עדכנית לנוער (לפי גיל: עד 16, 16–17, 17–18).
   - 7 חוקי הברזל: תשלום מלא על ימי התלמדות, איסור קנסות, שעות נוספות, והסעות בלילה.
   - מחשבון שכר מהיר ומחשבון ריבית דריבית חזותי.
   - קישורים ישירים לכלים ומחשבונים רשמיים (כל זכות, הנוער העובד, בנק ישראל, משרד העבודה).

5. **סימולטור מבחן כיתתי:**
   - אפשרות לבחירת תחום, מספר שאלות וטיימר.
   - הפקת דוח הערכה אישי עם ציון, ניתוח נקודות לחיזוק ואפשרות הדפסה להצגה לשירה בכיתה.

6. **מילון מונחים אינטראקטיבי:**
   - חיפוש מהיר וסינון לפי נושא של עשרות מושגי בגרות עם טיפים של שירה.

## 📁 מבנה ספריות החומרים הפדגוגיים (`materials/`)

החומרים מרוכזים בתיקיות מסודרות לפי מקצוע ולפי שכבות גיל:

```
materials/
├── civics/
│   ├── junior-high-grades-7-9/
│   │   ├── curriculum.md             # תוכנית הלימודים לחט״ב ומשימות ראמ״ה
│   │   ├── glossary.json             # מונחון מותאם לחט״ב
│   │   └── questions.json            # מאגר שאלות מובנה
│   └── high-school-grades-10-12/
│       ├── bagrut_syllabus_034281.md # מיקוד בגרות ומבנה שאלון 034281
│       ├── tsehes_methodology_guide.md # מדריך צה״ס למענה שאלת אירוע
│       ├── official_glossary_terms.json # מונחון מחייב של מפמ״ר אזרחות
│       ├── bagrut_event_questions.json # שאלות אירוע רשמיות ומחוונים
│       └── bagrut_knowledge_questions.json # שאלות ידע והשוואה
└── financial-education/
    ├── junior-high-grades-8-9/
    │   ├── curriculum.md             # התנהלות תקציבית וצרכנות נבונה
    │   └── scenarios_and_questions.json
    └── high-school-grades-10-12/
        ├── curriculum.md             # בנקאות, שוק עבודה, ריבית דריבית
        ├── youth_labor_rights.md     # מדריך זכויות מלא לשכר נוער
        ├── official_sources_and_calculators.json # כלים רשמיים
        └── practical_questions.json  # תרחישים מעשיים מהחיים
```
